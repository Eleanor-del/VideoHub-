VideoHub 视频聚合台是一款面向 Windows 的桌面视频聚合客户端，基于 Electron 开发，即装即用。它把分散在十余个网站的视频、直播与音乐收拢到同一个窗口：内置抖音、哔哩哔哩、快手、央视网、腾讯体育，以及虎牙、斗鱼、YY、映客等直播平台，
并接入咪咕音乐、酷我音乐、网易云音乐、QQ 音乐、5sing 等免登录音乐源，共 14 个内容源，一处搜索、一处收藏、一处观看。

界面既支持单平台浏览，也支持最多四列聚合分屏——列宽可拖拽、单列可关闭、顺序可调整；还能自建视频源（AI 智能识别或按名称索引），把任意站点加进来。免登录（游客）模式可减少登录弹窗，视频与图片支持无水印下载，误删的视频源可从「已删除（可找回）」
中一键恢复。
针对"上班摸鱼"场景，VideoHub 提供迷你小窗播放：窗口透明度可调、可在任务栏与 Alt+Tab 中隐身、可置顶悬浮，再配合老板键 Ctrl+Alt+H，一键隐藏全部窗口并静音，按一次原样恢复。所有收藏、历史与登录状态均保存在本地，卸载后彻底清除。
